# Classy Creepers Mod

The original Forge mod for Minecraft 1.8.9, which gives every creeper a top hat and monocle.

The source was decompiled with Vineflower from the released jar.

## Building

Run `./gradlew build` with Java 8. The mod jar, with Mixin bundled, is written to `build/libs`.
`./gradlew runClient` starts a development client.

Downloads are on the [releases page](https://github.com/CCBlueX/classy-creepers/releases).
