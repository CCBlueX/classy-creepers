# Classy Creepers Runtime Injection

Attaches to a running Minecraft 1.8.9 instance as a Java agent and gives every creeper a top hat and monocle,
without a mod loader.

The source was decompiled with Vineflower from the released jar.

## Building

Run `./gradlew build` with a Java 8 JDK. Its `tools.jar` (attach API) and ASM are bundled into the jar written
to `build/libs`.

## Usage

Run the jar on Windows while Minecraft is running. Downloads are on the
[releases page](https://github.com/CCBlueX/classy-creepers/releases).
